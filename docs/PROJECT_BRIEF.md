# Project Brief — ThermoCharge AI

## One-line pitch
ThermoCharge AI is a thermal-capacity intelligence platform for EV charging network operators that uses FortyGuard's hyperlocal temperature data to estimate heat-driven charging capacity loss and recommend operational actions before thermal constraints affect service.

## Problem
Installed charger nameplate capacity does not necessarily equal heat-adjusted usable capacity. Operators need a forward-looking thermal intelligence layer rather than learning about heat constraints only after performance falls.

## Core hackathon product
- Real South Phoenix fast-charging assets.
- Real FortyGuard heatmap and environmental context.
- Charger-to-GeoJSON-tile matching.
- Transparent capacity reference model.
- Auditable agent planner.
- Web operations dashboard.
- Commercial translation into kW/kWh/session impact.
- Clear provenance separating real, modeled, and demonstrated information.
